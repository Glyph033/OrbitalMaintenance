# Orbital Maintenance

A chill yet strategic space station maintenance simulator built on **Base Layer 2**.

You are the sole engineer keeping a massive orbital habitat alive. Manage oxygen, power, pressure, hull integrity, and life support systems before small problems turn into disasters.

### Features
- Real-time system monitoring
- Resource management and upgrades
- Procedural failure events
- Fully onchain progress (coming soon)
