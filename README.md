Orbital Maintenance — a relaxing yet tense space station management game running on Base Layer 2.You are the sole maintenance engineer responsible for keeping a sprawling orbital habitat operational. Every shift brings new challenges: failing oxygen filters, solar array malfunctions, micrometeorite impacts, and crew demands.Monitor and optimize core systems in real-time  
Upgrade redundant modules and emergency protocols  
Balance resources as small problems cascade into station-wide crises  
Unlock new sections of the station and advanced maintenance tech

Simple to learn, deep to master. One wrong decision and the station falls silent forever.Built fully onchain on Base Layer 2 your progress, upgrades, and station state are permanently stored on the blockchain.
